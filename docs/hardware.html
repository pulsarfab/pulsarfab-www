Supported hardware

Choose a device and integration, then check its SDK-free path and tested limits.

Cameras

Cameras work through native NINA, native Windows ASCOM, and Alpaca. The SDK backend is the default; Direct USB is experimental and never loads the camera SDK. Both use the same recovery controller.

The listed direct models can also use the SDK backend. ASI2600/6200 direct exposure limits are 2,000 seconds; hardware tests covered 1,200-second dark frames. Direct live view and trigger modes are not implemented. See camera setup and recovery.

The EFW hardware checks included calibration and full slot sweeps. Older EAF firmware, EAF Pro/Bluetooth, and dual-disc wheels are unsupported. Temperature compensation remains the imaging application's responsibility.

SDK-free still needs OS device access

  • Windows cameras: install the ZWO camera USB driver, including when using Direct USB.
  • Windows CAA, EFW, and EAF: use the built-in HID driver.
  • Windows FocusCube3 and OFP2: use USB Serial Device. Do not replace these accessory drivers with WinUSB/Zadig.
  • Linux/macOS: the host account needs USB, HID, or serial access. The SDK-free paths use native OS interfaces; SDK mode also needs its vendor library and runtime dependencies.

NINA and native COM require Windows x64; the ASCOM drivers support 32-bit and 64-bit clients. The Rust workers and Alpaca server build on Windows, Linux, and macOS, with Linux/macOS CI builds for x86-64 and ARM64. See installation requirements and portable setup.

What has been verified?

Physical-device validation is documented per model. Linux/macOS physical USB validation remains incomplete, and simulator tests do not establish hardware support. Camera USB recovery tests used controlled faults, not cable removal or power loss. A full ASCOM ConformU run remains outstanding.

Protocol traces and evidence are in the source documentation. Screenshots retain explicit physical-device, simulation, or historical labels. For a new camera, the separate CameraKit collects local diagnostics and SDK USB traces without uploading automatically.
